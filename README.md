# DESIGN LINEAGE｜デザイン表現史

静的なデザイン史図鑑の公開研究版です。学校・歴史運動・様式・技法・現代トレンドを区別し、一次資料と作品の観察から説明します。

- 本文35項目／収録候補88項目。残り53項目は調査中です。
- 一覧に登録した項目の実作品の代表画像46点、参照・関連実作品2点。3点の比較セットが揃う項目は9件です。
- AI制作の接続解説図1点（Dessau接続模型）、新しいオリジナル比較図4点。歴史画像数には含めません。
- Grid systemsの自作4図、Bauhaus色形図、入口の4図も歴史代表作ではありません。
- 全項目完成・網羅性の世界一・全画像の世界共通な自由利用を主張しません。

## 配信

## 素材の利用条件

サイト全体や画像に一括のオープンライセンスは付けません。実作品は各図のcredit/source/licenseと `adopted-image-rights.json`、`reference-image-rights.json` をご確認ください。CC0、Public Domain Mark、CC BY 2.0、CC BY-SA 4.0は別です。CC BY写真は作者・原写真URL・ライセンス・縮小変更の表示を保ちます。原作品と写真の条件も別です。

Red WedgeはCommons個別PDM表示に基づく関連資料です。スキャン元個体・撮影者は不明で、美術館提供画像とは称しません。複製台帳にその留保を記載しています。

Dessauは現代のAI制作接続解説図で、写真・図面の転載や原作の完全模写ではありません。CC0や包括的な商用再利用保証を付けていません。

原作と近似する6つの旧生成試作（Schmidt、Brandt、Normandie、Balla、Beethoven、Carlton）は一般公開版に含めず、私有制作資料に保存しています。権利侵害と断定したためではなく、公開・将来商用の適合確認が未完了のためです。各様式には実作品や独自比較図・一次資料リンクを残しています。

第三者HTMLの保存証拠、私有制作資料、未採用画像、認証情報はこのリポジトリに含めません。本文35項目と代表候補165件は、専門用語を説明する平易な日本語へ改稿しました。画像充実は継続中です。採用ロゴ10を全ページと共有画像・アイコンへ適用しています。

## AAGAの制作方針

AAGA｜AI Agent Generated ART。品質を最優先に、代表作品を敬意をもって研究し、完全模写を目指します。原作を意図的に改変することを目的にしません。試作に残る差異や再現上の限界は個別に明記し、完全再現できたとは表示しません。原作と写真の利用条件は別に確認します。

この公開第一版では完成AAGAは0点です。原作を意図的に変えた旧試作は完成模写として公開せず私有保存。独自の様式比較図とAI制作接続図は、原作模写と別分類です。

Bauhausの実画像3点は、学校の展覧会案内1点と1923年教員版画集の2葉です。家具・建築を含む全分野の画像が揃ったという意味ではありません。愛知県美術館の2画像は個別Public Domain Mark指定で、CC0とは区別します。
