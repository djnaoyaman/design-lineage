# DESIGN LINEAGE の読者体験

編者がこの図鑑に込めた狙いは、作品を見比べる楽しさから、様式の違いやつながりに気づいてもらうこと。ひとつの読書体験の目安を「二つの作品の違いを一つ、自分の言葉で話せる」と置く。年代や影響関係の説明は、個別の記事と出典が支える。

## 入口を選べるようにする

| 読者の関心 | 現状を調べて分かったこと | 今回の設計 |
| --- | --- | --- |
| まず絵を見たい | 作品選には36記事の図版があり、拡大して眺められる。 | 1記事1枚のスクロール展示を生かす。拡大画面で記事を読むか、その項目を比較に持ち込むかを選べる。 |
| どこを見ればいいか知りたい | 比較ページの上の図版が固定され、選んだ項目と食い違っていた。 | トップから三つの問いへ案内する。選択した2項目に図版・観察の手がかり・出典が連動する。画像を所蔵していない項目には本文の作品・制作例を使う。 |
| 名前や時代から調べたい | 項目索引と年表があり、年表では比較相手がデータ上の順序で選ばれていた。 | 下部の初期表示は「項目で探す」。年表からの比較に出発点を引き継ぎ、編集した問いと記事中の関連項目を優先する。対応する相手がなければ読者が選ぶ。 |
| 記事を読み終えた | 記事末の前後移動は図鑑と同じ年代順。主題を変えずに別の作品と比べる操作は記事上部にある。 | 記事末にも比較の入口を置く。比較画面から個別の図版・解説へ戻れる。 |

## 最初に用意した三つの問い

- **視線はどこへ進む？**　バウハウスの展覧会案内では赤い見出しを、琳派の《八橋図屏風》では折れ曲がる橋を追う。
- **器のどこに飾りを置く？**　ロココの銀器の縁とふた、アール・デコのワイングラスの軸を見る。
- **余白に色を置くと？**　ウィーン分離派の展覧会ポスターと中島英樹の《Unfinished #3-1》で、黄色の面積と置き場所を比べる。

ここで取り上げる組み合わせは観察のための編集例。影響関係を紹介する場合は、関係を裏づける記録を個別に示す。

## 公開後に確かめたいこと

1. 初見の読者に一組を選んでもらい、二作品のどこに違いを見つけたかを尋ねる。画面上の解説を読む前後で、答えに具体的な箇所が出てくるかを見る。
2. 利用状況を計測する場合、第一指標は「比較を開いた訪問のうち、比較対象の記事を少なくとも一つ開いた割合」。補助指標は「ギャラリーで拡大した訪問のうち、記事または比較へ進んだ割合」。理解そのものは上の読者観察で確かめる。
3. 次に増やすのは、見比べたいのに図版のない組み合わせ。読者観察と利用状況から選び、作品を選定し、所蔵元と画像の利用条件を確認して加える。

計測値は未取得。今回の公開候補には新しい計測コードを含めていない。公開はプレビュー確認後にこの変更を main にマージすると GitHub Pages の既存配信に反映される。
