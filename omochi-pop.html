はっきり、まるく、あそび心。

『おもちの文鳥ぐらし』の制作過程で生まれた、編者独自のデジタルデザイン。

ニューブルータリズム、レトロモダン／レトロフューチャリズム、メンフィスの要素を組み合わせた様式です。

3つの要素とキーワード代表作・参照例生まれたゲームへ出典と画像について

THREE INFLUENCES

3つの表現を、画面の中へ。

輪郭で操作する場所をはっきりさせ、丸みで親しみをつくり、色と模様で楽しさを添える。異なる時代の表現を、現代のデジタル画面へ組み合わせます。

01 / OUTLINE + SHADOW

ニューブルータリズム

Neubrutalism / Neo-Brutalism

  • 黒く太い輪郭線で、要素やボタンをはっきり囲む。
  • 高コントラストな配色と、ビビッド／レトロな色を組み合わせる。
  • フラットな色面を基本に、ぼかさない影や境界で奥行きを見せる。

キーワード：太いアウトライン・硬い影・フラットな色面・明快な操作

図鑑の解説を読む →
02 / ROUND + RETRO

レトロモダン／
レトロフューチャリズム

Retro Modern / Retro-Futurism

  • 大きな丸みのあるアーチや、やわらかな幾何学を使う。
  • 懐かしさのある色やイラストの感覚を、現代のアプリUIへ取り入れる。
  • 過去に描かれた「未来」の印象を、今の視点で楽しむ。

キーワード：アーチ・曲面・幾何学・懐かしい未来・70〜80年代のポップ感

ミッドセンチュリーの背景を読む →
03 / COLOR + PATTERN

メンフィス・スタイル

Memphis Style

  • パステルカラーやポップな色を、意外な組み合わせで並べる。
  • 丸・三角・波線などの幾何学パターンを取り入れる。
  • 整いすぎないリズムや、おもちゃのような楽しさをつくる。

キーワード：幾何学パターン・色の対比・遊び心・非対称

メンフィスの歴史と作品を読む →

年代は、重ねずに見分ける。

ミッドセンチュリー・モダンは主に20世紀中頃のデザインを指します。70〜80年代全体をそのままミッドセンチュリーとは呼びません。ここでは、1949年の《ボール・クロック》、1970年の《ヴィジョナ II》、1981年に発表されたメンフィスを、それぞれ異なる背景として紹介します。レトロモダンは懐かしさを現代に取り込む考え方、レトロフューチャリズムは過去の未来像を見直す表現として使い分けています。
